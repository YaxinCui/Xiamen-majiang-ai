# 厦门麻将 AI

本项目从可测试的“核心金牌版”厦门麻将规则开始，提供一个本机运行的
`1 人 vs 3 个 Teacher AI` 单局网页麻将桌。它是后续导出教师轨迹、监督
训练、DAgger 和 hybrid 推理的规则正确性基线，不会把 AI 暗牌或牌墙顺序
发送给浏览器。

## 运行网页游戏

只需要 Python 3.11+，没有第三方依赖：

```bash
python3 scripts/serve_web_game.py --host 127.0.0.1 --port 8765
```

浏览器打开 `http://127.0.0.1:8765`。局域网体验可将 `--host` 改为对应
内网地址或 `0.0.0.0`；该版本没有账号与公网访问控制，不应直接暴露到互联网。

## v1 规则范围

- 4 人、144 张牌，花牌自动补牌；支持吃、碰、明杠、暗杠与补杠。
- 翻金：指示牌的下一张同类牌是金牌，金牌为万能牌；打出的金牌不可被响应。
- 支持标准和与七对。游金、三金倒、跟打及复杂底/水制保留为后续规则开关，当前关闭。
- 简化结算：底分为 8；自摸三家各付，点炮由放铳者支付三份；手中花牌和金牌数量提高倍率。

本规则集综合了公开厦门麻将资料中的稳定共同部分；地方规则存在差异，因此发布前需要以本地确认规则替换或启用对应开关。
