# 参数化弃牌规则 Teacher v1：训练与筛选协议

日期：2026-08-08
状态：独立 validation 未通过；正式 100 墙未读取

## 假设

`HeuristicTeacherAgent` 的普通弃牌排序本来就是一个小型线性规则模型：完整刻子、对子余数、相邻搭子、嵌张搭子、顺子重叠、等待牌种、金牌保留分别乘固定权重。现有权重由人工设定，并没有用厦门 classic 的整局得分校准。

本路线不引入 Transformer，也不重新学习规则。只暴露普通弃牌的线性权重，用四座轮换自博弈整局得分训练；胡牌、游金、金牌锁、合法动作、吃碰杠和响应决策继续完整继承 frozen Teacher。这是规则模型与小 residual 之间的低算力中间态。

## 模型边界

默认权重必须逐动作精确重建 frozen Teacher：

| 分量 | frozen 权重 |
| --- | ---: |
| 已有副露 | 28 |
| 手牌中金牌 | 12 |
| 完整刻子组 | 14 |
| 对子余数 | 5 |
| 相邻搭子重叠 | 2.5 |
| 隔一张搭子重叠 | 1.25 |
| 顺子重叠 | 5 |
| 直接等待牌种 | 18 |
| 弃金额外惩罚 | 7 |

因同一弃牌状态中“已有副露”为常数、非弃金候选的金牌数也相同，并且所有结构权重存在整体缩放不辨识，v1 只搜索六项：刻子、对子、相邻、隔张、等待、弃金额外惩罚。已有副露 28、金牌 12、顺子 5 固定。

所有搜索权重为 frozen 值乘以 `exp(log_multiplier)`；`log_multiplier` 固定截断在 `[-1.5, 1.5]`，权重保持有限非负。

## 固定演化训练

- RNG：`202626400`。
- 训练墙分段：`202626500..202626519` 与 `202626600..202626619`，每段 20 个物理墙，每墙四座轮换。
- 每个候选的 fitness 先取两个分段中较低的候选均分，再用两段均分平均值破同分。
- CEM：4 代、每代 12 个候选、每代保留 4 个 elite；初始 log sigma 0.45，逐维按 elite 更新并截断到 `[0.12, 0.60]`。
- 第 1 代包含 frozen 原点；后续每代包含当前中心。所有候选使用相同训练墙。
- 训练完成后只冻结全程 fitness 最好的一个候选，不根据验证结果改选第二名。

训练得分用于参数学习，不构成强度证据。

## 独立验证与正式筛选

1. validation：`seed=202627000` 起 100 个新物理墙、四座轮换。只有候选均分严格大于 0，才允许进入正式筛选；否则路线停止。
2. validation 后将唯一候选的精确权重和结果写入本协议，再创建常量化 selection 脚本，不得修改权重。
3. 正式 selection：`seed=202628000` 起 100 个新物理墙、四座轮换；同墙 reference 为 frozen Teacher。
4. 唯一晋级门槛：`paired_seed_score_delta_95pct_low > 0`。未通过即淘汰，不在 validation 或 selection 墙上调参重跑。
5. 即使通过，也只进入人工复核；不自动接入网页、替换标签或声称超过普通人类。

## 资源与失败条件

- CPU 执行；不使用 GPU。
- 搜索只允许上述 48 个代内候选，不扩 population、代数或权重维度续命。
- 默认参数化模型必须通过与 frozen 行为完全一致的单测。
- 任一权重为负、NaN、Infinity，或候选读取墙／对手暗手，立即失败。
- 若 validation 均分不大于 0，正式 `202628000..202628099` 保持未读。

## 结果

已按固定 48 候选预算完成 CPU 演化。训练最优候选来自第 0 代第 6 项：

| 权重 | frozen | 训练候选 |
| --- | ---: | ---: |
| 刻子 | 14 | 16.2035 |
| 对子 | 5 | 4.1450 |
| 相邻 | 2.5 | 1.0870 |
| 隔张 | 1.25 | 1.5728 |
| 等待 | 18 | 28.0139 |
| 弃金额外惩罚 | 7 | 9.6437 |

两个 20 墙训练分段均分分别为 **+5.175** 与 **+1.975**，worst-segment fitness 为 +1.975。但在从 `seed=202627000` 起的 100 墙独立 validation 中，候选只有 93/400 胜，总分 −612、均分 **−1.53 ± 1.1566**，胜率 23.25%。

因此状态为 `validation_rejected_selection_unread`。正式 `202628000..202628099` 没有读取，候选不部署、不生成标签，也不扩大同一搜索预算续命。

失败解释：40 个训练墙上的稀疏终局得分不足以稳定校准 6 个非连续动作排序权重；训练正收益没有泛化。下一路线应对同一分歧状态做配对反事实 rollout，以动作间终局差降低墙与座位方差，再训练一个高置信 residual，而不是继续增加演化候选。
