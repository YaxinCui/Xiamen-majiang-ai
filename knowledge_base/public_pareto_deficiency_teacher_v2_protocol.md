# 公开向听—有效进张 Pareto Teacher v2 协议

状态：`selection_rejected`
日期：2026-08-08

## 假设

公开知识向听 v1 在 frozen Teacher 近分的非听牌普通弃牌中，只要求标准向听严格减少。它在全新 100 墙得到
`+0.2675` 的点估计，但 95% 区间为 `[-1.4671,+2.0021]`；其缺陷是允许用大量公开有效进张交换一向听。

抚州项目当前源码的生产 hybrid 并非纯神经策略：`lookahead_value` 参考分数以权重 20 锚定动作，网络和
`progress_static_risk` 主要处理参考分数并列。迁移到厦门时不复制其规则或参数，只采用“参考近分时做保守消歧”这一结构。

本候选固定为 v1 的只减法确认层：候选必须同时满足：

1. frozen Teacher 原分差不超过 `2.0`；
2. 双方均为非听牌普通弃牌，且不涉及游金、金牌锁或特殊档位；
3. 精确标准向听严格低于 frozen；
4. 按本家手牌、公开牌河、副露和翻金计算的下一摸有效进张剩余张数不低于 frozen。

第 4 条失败时严格回退 frozen。它不读取真实牌墙、对手暗手、未来随机数或终局赛果，也不增加 v1 未提出的新动作。

## 固定筛选

- profile：`classic`
- score margin：`2.0`
- selection：100 副物理牌墙，`seed=202638000..202638099`
- 每墙四座轮换；候选一席，对手三名 frozen `HeuristicTeacherAgent`
- 同墙 Teacher baseline
- 唯一晋级门槛：`paired_seed_score_delta_95pct_low > 0`
- 不在本批墙上修改 margin、Pareto 条件、tie-break 或追加邻域权重
- 未过门槛时不部署、不蒸馏、不生成训练标签

报告只保存聚合胜负、分数、覆盖数、v1 proposal 数、Pareto 拒绝数、向听减少量和有效进张变化；不保存手牌、
牌墙、seed 对应的逐局 trace 或对手暗手。

## 固定结果

全新 100 墙已按协议完成。3,263 次候选弃牌中，向听 v1 提出 70 次动作变化，但 70 次全部会减少公开有效进张，
因此 Pareto 层全部否决，候选逐局与 frozen Teacher 完全一致：均分 `0.0`、paired 区间 `[0.0,0.0]`。

这不是强度平局候选，而是结构性空策略：在该访问分布中，“严格少一向听”与“不减少公开有效进张”没有交集。
状态固定为 `selection_rejected`，不部署、不蒸馏、不放宽 Pareto 条件。报告 SHA-256：
`7a60f963220ea5c536ec7e42e4f5e4feea6ba1e4af571f88e696b1d78092dca7`。

## 与既有失败路线的区别

- 不像全局一步前瞻那样替换全部弃牌评分；
- 不像向听 v1 那样允许牺牲有效进张；
- 不像 TwoDraw v1/v2 那样估计两次摸牌概率或运行昂贵 DP；
- 不像小 MLP gate 那样把 Teacher 模仿置信度当动作优势；
- 不重新拟合任何规则权重。
