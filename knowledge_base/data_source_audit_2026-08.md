进入「厦门 classic、可见信息策略」的数据入口。

## 当前结论

截至本次只读检索，**没有发现可直接用于训练的、明确授权的厦门 classic 专家牌谱**。
这不是对互联网作出的不存在性证明；它是本项目当前数据清单的审计状态。没有通过下述
准入条件的来源一律不进入训练、评测或模型初始化。

## 未来数据准入契约

某一批外部或本地记录只有同时满足全部条件才可被解析为候选训练输入：

1. **授权**：记录发布者或参与者明确允许研究／训练用途；保留来源、许可证和版本身份。
2. **规则一致**：能按 `xiamen-classic-full-v2` 重放；须验证 144 张物理多重集、补花、翻金、金／白板、
   16／17 张手牌、合法响应和结算。规则不确定则单独隔离，不能用动作标签。
3. **信息集安全**：每一决策仅保留行动者手牌、当时可见的河／副露／花／金、合法动作、选择和公开历史。
   删除其他玩家暗手、牌墙顺序、随机种子、账号、设备和时间标识；完整暗杠牌面也不得在他家观察中出现。
4. **完整性**：按物理牌局而非决策行切分；校验每张牌守恒、动作合法、结果可重放、无重复局和无跨规则／
   跨对手身份混合。
5. **评测隔离**：至少保留从未用于训练、选 epoch 或调超参的人类对局。行为克隆的离线准确率不能替代
   该留出集上的人类 A/B 结果。

本地 `local_human_data/` 已实现一条更窄的 opt-in 通道：日志默认被 Git 忽略、默认拒绝训练，并须经过
`scripts/audit_human_trajectories.py` 与人工复核。这是目前唯一已实现的可安全接入途径；本次审计时该目录为空。

## 对模型路线的影响

跨规则牌谱最多可以在未来、经独立许可后用于非监督的通用事件表征研究；在没有已验证的厦门映射前，
它们不能预测厦门合法动作、对局价值或游金决策。当前更强模型的启动信号仍只能来自：

1. 经过上述审计的同规则真人行为数据；或
2. 一个独立牌墙和固定异质对手阵容上通过门槛的、公开信息安全的新 Teacher。

因此本项目不会为了扩大样本量而混用其它麻将变体、未知来源的线上记录或旧 rejected checkpoint。

### 已否决的跨变体预训练捷径

本次还专门核验了「仅以公开弃牌／副露序列表征预训练，再在厦门数据上微调」这一方向。它在方法上可能
值得日后研究，但当前没有一个同时具备**原始来源授权可核验、可过滤为 actor-visible 事件、且不含日麻
动作／价值监督**的候选语料。因此它不是当前训练实验的起点；待获得书面授权的来源后，必须先实现一个
fail-closed 转换器和逐牌局审计，再单独预注册表征迁移对厦门留出集的增益检验。

## 2026-08-08：外部厦门牌谱定向检索

定向检索 GitHub、Gitee 和公开数据页面，没有发现可确认规则、来源授权和完整行动历史均匹配本项目 classic 的厦门麻将牌谱。检索结果主要是 Tenhou／雀魂日麻、国标 MCR、四川血战等变体；即使数据量很大，也不能把其动作当作厦门的正确标签。

其中 IJCAI-2026 国标麻将公开语料可用于研究数据格式与大样本评测纪律，但番种、手牌张数、动作和结算与厦门不一致；不下载、不转换、不预训练。当前同规则优势来源仍限于本地明确授权的人类纠错／对局，或经独立门槛验证的规则 SlowExpert。

### 可以迁移的只有实验方法

该工程报告的以下方法可由本项目独立实现，不需要接触其数据、权重或代码：

1. 三个独立随机种子训练，并在合法动作上平均 softmax；只有三个种子都稳定时才讨论集成。
2. 使用同一批预注册牌墙做 duplicate／四座轮换，并保留 matched difference，而非比较两次独立自博弈均值。
3. 对计分器、番数接口和异常返回值写黄金测试；任何“所有和牌分数为零”一类 instrumentation 故障都必须在训练前失败。
4. 在有限算力上先跑小网络、短机械验证和 matched-null；未经独立收益验证，不扩大到深残差网、搜索或长周期 RL。
5. 行为克隆只定义锚点，不能制造超过数据来源的新知识；没有同规则更强标签或可信反事实时，继续扩大蒸馏规模的预期收益接近零。

这些方法只改变实验协议，不改变本次数据准入结论。厦门项目当前仍等待真实的同规则人工盲评标签；不得用 MCR 数据填补该缺口。
