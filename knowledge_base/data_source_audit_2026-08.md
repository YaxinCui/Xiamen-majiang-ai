准入条件的来源一律不进入训练、评测或模型初始化。

## 未来数据准入契约

某一批外部或本地记录只有同时满足全部条件才可被解析为候选训练输入：

1. **授权**：记录发布者或参与者明确允许研究／训练用途；保留来源、许可证和版本身份。
2. **规则一致**：能按 `xiamen-classic-full-v2` 重放；须验证 144 张物理多重集、补花、翻金、金／白板、
   16／17 张手牌、合法响应和结算。规则不确定则单独隔离，不能用动作标签。
3. **信息集安全**：每一决策仅保留行动者手牌、当时可见的河／副露／花／金、合法动作、选择和公开历史。
   删除其他玩家暗手、牌墙顺序、随机种子、账号、设备和时间标识；完整暗杠牌面也不得在他家观察中出现。
4. **完整性**：按物理牌局而非决策行切分；校验每张牌守恒、动作合法、结果可重放、无重复局和无跨规则／
   跨对手身份混合。
5. **评测隔离**：至少保留从未用于训练、选 epoch 或调超参的人类对局。行为克隆的离线准确率不能替代
   该留出集上的人类 A/B 结果。

本地 `local_human_data/` 已实现一条更窄的 opt-in 通道：日志默认被 Git 忽略、默认拒绝训练，并须经过
`scripts/audit_human_trajectories.py` 与人工复核。这是目前唯一已实现的可安全接入途径；本次审计时该目录为空。

## 对模型路线的影响

跨规则牌谱最多可以在未来、经独立许可后用于非监督的通用事件表征研究；在没有已验证的厦门映射前，
它们不能预测厦门合法动作、对局价值或游金决策。当前更强模型的启动信号仍只能来自：

1. 经过上述审计的同规则真人行为数据；或
2. 一个独立牌墙和固定异质对手阵容上通过门槛的、公开信息安全的新 Teacher。

因此本项目不会为了扩大样本量而混用其它麻将变体、未知来源的线上记录或旧 rejected checkpoint。
