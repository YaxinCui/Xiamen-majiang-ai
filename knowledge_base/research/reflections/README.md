# 我的感悟区

## 1. 厦门麻将更难，但“规则更复杂”不是唯一原因

厦门麻将的 16/17 张结构、金牌代理、游金、花牌替换、跟字和特殊结算增加了状态分支；但模型没有超过 Teacher，核心原因还包括：
Teacher 标签的上限、罕见事件覆盖不足、终局分数高方差，以及从零 RL 缺少稳定的长程 credit assignment。

## 2. Rule → Neural 之间必须有中间态

最有希望的中间态是公开信息 lookahead / afterstate value / Teacher-anchored residual 的组合。它能把“规则正确性”和“策略泛化”
分开验证；只有静态牌效分数的一步前瞻已经被本项目独立实验否定，说明中间态必须考虑后续牌效、规则事件和公开可见余牌，而不是简单加一个分数。

## 3. 数据少只是表象，数据质量和分布更重要

Teacher self-play 产生大量数据并不等于产生新知识：它最多让网络复制 Teacher。要获得超越 Teacher 的信号，需要人工高质量牌谱、独立搜索、
多样对手池或反事实 outcome；同时按整副物理墙切分，避免四座轮换泄漏。

## 4. 点估计为正不等于更强

本项目的一摸听牌候选在 160 墙点估计为正，但置信区间跨零；用户要求的 400 墙复核仍为 `+0.512` 分/局且区间
`[-0.755,+1.779]`，继续跨零。因此当前判断是“没有证明更强”，不是“候选一定更弱”。
日常开发用 100 墙提高迭代速度，晋级仍必须由独立墙和下界门槛决定。

## 5. 下一步可证伪问题

- 一个只针对游金/跟字/响应时序的局部搜索教师，是否比全局弃牌前瞻更有覆盖？
- outcome value 是否能在不读取暗牌的 actor 路径中提供更稳定的 afterstate 标签？
- Teacher-anchored 网络在异质对手池中是否能减少“对 Teacher 适应”而非提升真实牌力？

每个问题都必须先写协议、固定 100 墙筛选，再决定是否扩大。

## 6. 跨规则大数据不能修复同规则知识缺口

IJCAI-2026 国标麻将语料有数万局，但其 13／14 张流程、235 动作和番种体系与厦门 classic 不同。把它并入训练会让样本数变大，
却会把错误的动作先验和价值函数写进模型；这不是预训练红利，而是难以定位的负迁移。只有不携带规则语义、授权清楚且通过独立
消融的表征目标，未来才值得研究。目前仍应把预算放在同规则人类纠错和可审计的局部 oracle 上。

## 7. 最新工程的负结果支持“小模型＋更好信号”

2026 国标竞赛工程记录了模仿学习强锚点之后，PIMC、belief weighting、value／Q、AWBC 和自博弈 RL 多次停滞或在扩大复核后消失；
真正稳定的收益更多来自网络／计分器故障修复和三随机种子集成。对本项目的推论不是照搬其模型，而是先证明标签提供了 Teacher
之外的信息，再训练小 residual；否则更深网络只会更精确地复现现有 Teacher，或更快地过拟合高方差终局回报。

## 8. 训练管线本身也是待验证模型

一次计分接口解包错误就可能让所有和牌监督归零，而 loss 仍能正常下降。因此每轮训练前必须验证四件事：规则黄金样例、标签非退化
分布、策略头确实能越过锚点、matched-null 不产生虚假优势。只有这四项都通过，固定墙实战结果才值得解释。

## 9. 与其伪造反事实标签，不如付出随机试验的方差成本

同一个公开状态只发生一次，不能从终局结果直接断言另一张牌更好；同一真实隐藏墙的双分支又会把 actor 不知道的世界写进标签。
top-2 0.5/0.5 单点随机干预选择了更慢但诚实的路线：每个样本只观测一个处理结果，以 propensity 和大量独立墙换取无偏总体
比较。代价是 pilot 墙级标准差约 38 分，因而正式数据必须上千墙并限制模型容量；收益是 validation 失败时能明确归因于“没有
可复现的条件优势”，而不是继续争论标签是否泄漏。

## 10. 降噪成功不等于策略成功

同墙另外三条座位轮换可以作为与当前 0.5/0.5 动作独立的 control variate。它在全新 2,000 墙上把四个覆盖门的标准误降至
原来的约 47%–72%，证明统计工程不是训练集幻觉；然而所有 Bonferroni 下界仍跨零。这个结果很重要：它把“看不清”推进到
“看得更清楚但优势仍太小”。下一步不应继续增加同一 top-2 网络容量或墙数，而应改变 Teacher 外部改进信号，例如真正的
盲态人工纠错或经过独立校准的局部搜索标签。
