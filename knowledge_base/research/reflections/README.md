# 我的感悟区

## 1. 厦门麻将更难，但“规则更复杂”不是唯一原因

厦门麻将的 16/17 张结构、金牌代理、游金、花牌替换、跟字和特殊结算增加了状态分支；但模型没有超过 Teacher，核心原因还包括：
Teacher 标签的上限、罕见事件覆盖不足、终局分数高方差，以及从零 RL 缺少稳定的长程 credit assignment。

## 2. Rule → Neural 之间必须有中间态

最有希望的中间态是公开信息 lookahead / afterstate value / Teacher-anchored residual 的组合。它能把“规则正确性”和“策略泛化”
分开验证；只有静态牌效分数的一步前瞻已经被本项目独立实验否定，说明中间态必须考虑后续牌效、规则事件和公开可见余牌，而不是简单加一个分数。

## 3. 数据少只是表象，数据质量和分布更重要

Teacher self-play 产生大量数据并不等于产生新知识：它最多让网络复制 Teacher。要获得超越 Teacher 的信号，需要人工高质量牌谱、独立搜索、
多样对手池或反事实 outcome；同时按整副物理墙切分，避免四座轮换泄漏。

## 4. 点估计为正不等于更强

本项目的一摸听牌候选在 160 墙点估计为正，但置信区间跨零；用户要求的 400 墙复核仍为 `+0.512` 分/局且区间
`[-0.755,+1.779]`，继续跨零。因此当前判断是“没有证明更强”，不是“候选一定更弱”。
日常开发用 100 墙提高迭代速度，晋级仍必须由独立墙和下界门槛决定。

## 5. 下一步可证伪问题

- 一个只针对游金/跟字/响应时序的局部搜索教师，是否比全局弃牌前瞻更有覆盖？
- outcome value 是否能在不读取暗牌的 actor 路径中提供更稳定的 afterstate 标签？
- Teacher-anchored 网络在异质对手池中是否能减少“对 Teacher 适应”而非提升真实牌力？

每个问题都必须先写协议、固定 100 墙筛选，再决定是否扩大。
