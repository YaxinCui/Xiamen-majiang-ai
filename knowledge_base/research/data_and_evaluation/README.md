# 数据与评测区

## 数据分层

- `teacher_selfplay`：冻结规则 Teacher 生成，只能说明模仿能力。
- `search_oracle`：公开信息搜索或 afterstate 结果，必须记录搜索边界和是否使用 privileged 状态。
- `human_opt_in`：经过隐私、规则档和会话审计的真人数据；默认不进入训练。
- `evaluation`：只读强度记录，永远不能回流训练或选 checkpoint。

不同来源必须分文件、分 manifest、分物理墙 seed；不能把评测 JSONL 当训练 JSONL。

## 默认统计协议

- 常规筛选：classic 连续 100 副独立物理墙。
- 每副墙：候选四座轮换，其他三席固定且命名的对手。
- 统计单位：每副物理墙四座平均，而不是把四局当作四个独立样本。
- 必报字段：净分、胜率、流局、放铳/被和、特殊规则触发、非法动作和运行版本。
- 400 墙只用于通过 100 墙筛选后的确认，不能按结果改参数。

## 解释规则

点估计为正但置信区间跨 0，只能写“未证实更强”；区间下界严格为正，才可以进入下一层筛选。
模仿准确率、训练 loss、单局胜负和候选自博弈分数都不能单独替代同墙四座评测。
