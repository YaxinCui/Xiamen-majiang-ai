# 厦门规则与引擎区

这里是本项目的规则事实源，不以论文或其他麻将项目的规则替代代码与测试。

## 当前事实源

- 规则配置：`xiamen_mahjong/rules.py`
- 状态机与动作合法性：`xiamen_mahjong/game.py`
- 胡牌、听牌和金牌结构：`xiamen_mahjong/hand.py`
- 分数与水：`xiamen_mahjong/scoring.py`
- 规则回归：`tests/test_game.py`、`tests/test_hand.py`
- 规则说明：`RULES_RESEARCH.md`

## 每次规则修改必须回答

1. 初始手牌、摸牌、补花、金牌和游金状态的牌数是否守恒？
2. 吃、碰、明杠、暗杠、补杠和抢杠的响应优先级是否一致？
3. 跟字限制是否同时作用于普通弃牌、杠和响应后的强制弃牌？
4. 胡牌、流局、庄家连庄和多家得分是否在四座轮换下零非法动作？
5. 新规则是否改变了已有训练数据的语义？若改变，旧数据必须隔离而不是静默混用。

## 研究边界

学习策略只能在引擎给出的合法动作集合中排序；规则引擎拥有最终裁决权。任何论文中的“麻将规则”只有在映射到本区并有测试后，才能进入训练。
