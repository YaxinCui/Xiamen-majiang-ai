# 强化学习技术区

## 推荐训练阶梯

1. **规则与环境**：动作 mask、花牌替换、金牌/游金、跟字、吃碰杠响应和结算先通过单元测试。
2. **Teacher 基线**：保留可解释的牌形/等待/公开余牌规则；记录决策覆盖率，不把 Teacher 自我模仿准确率当强度。
3. **辅助监督**：从 Teacher 或独立搜索得到 action、route、wait、score、win-type 等多任务标签；标签必须按物理墙切分。
4. **Teacher-anchored actor**：让网络从 Teacher 策略出发，残差为零时严格等于 Teacher；只有独立评测证明改善才放大残差。
5. **DAgger / 反事实数据**：让候选访问真实状态，再由 Teacher/搜索标注；候选访问分布与训练标签分布必须分别审计。
6. **局部价值与搜索**：优先做 response/afterstate 子问题，再考虑 belief、CFR 或公共状态搜索；终局净分只作为长程信号。

## 信息集约束

部署 actor 只能看到本家暗手、四家公开河牌/副露、公开事件和规则状态。墙顺序、对手暗手、未来摸牌和训练期 oracle 只能进入：

- 训练期 privileged critic；
- 只读诊断；
- 独立搜索的内部模拟。

它们不能进入网页策略、训练导出的 actor 特征、JSONL 标签或 checkpoint 的 actor 路径。

## 评测与数据

日常评测固定 100 副物理墙、四座轮换、同一对手阵容和同一随机种子范围；物理墙均值是统计单位，不能把四个座位当四个独立样本。
候选必须同时报告平均净分、胜率、流局、放铳/被和、特殊规则触发率和非法动作数。100 墙是筛选门，不足以给出“超过人类”结论；
确认实验可扩展到 400 墙或更多，但不得事后根据结果改参数。

## 当前项目的 RL 结论

从零 PPO/共享策略自博弈在本项目稀疏终局回报上不稳定；Teacher-anchored residual 可以保证不退化，但目前没有证明正向优势。因此下一步优先级是
提高专家信号质量、覆盖罕见游金/响应状态、构造独立 afterstate outcome，而不是盲目增加 PPO 轮数。
