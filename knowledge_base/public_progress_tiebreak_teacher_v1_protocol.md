# Teacher 完全并列公开进展消歧 v1 协议

日期：2026-08-08
状态：`selection_rejected`

## 源码审计结论

抚州仓库 commit `53f73d2495c4a49790ab2af7c064906cd5d9fd2b` 的当前生产配置使用
`lookahead_value` 作为 reference、reference 权重 `20.0`，并用 `progress_static_risk` 处理 reference 的最高分并列。
其长期记录还显示，在两个 200-set 诊断中，旧生产 hybrid 相对 lookahead 的分歧分别有 `1744/1761` 和
`1737/1746` 来自 reference tie-break，真正的 base-model blend 只有 `11` 和 `7`。因此可迁移结论不是“神经网络
推翻强规则”，而是“粗参考分数保留下限，公开进展只处理完全并列”。

## 厦门候选

frozen `HeuristicTeacherAgent` 在相同最高分时按牌号顺序选第一张。本候选只检查最高分**完全相等**的非金牌普通弃牌，
并用 actor-visible 信息计算每个弃牌后的：

- 精确标准向听；
- 下一次本家摸牌可严格降低向听或直接胡牌的公开剩余张数；
- 其中立即胡牌的公开剩余张数。

只有另一张完全并列牌在“向听不高、有效进张不低”上 Pareto 支配 frozen，并至少一项严格改善时才改变动作。排序固定为
低向听、高有效进张、高立即胡牌张数、低牌号。游金、金牌锁、非 classic、金牌最高项和所有响应/杠/胡仍回退 frozen。
候选不读真实墙、其他玩家暗手、future RNG 或 outcome。

## 只读覆盖诊断

classic `202638220..202638229` 的 10 副墙只读取动作覆盖，不将内部终局结果用于参数或门槛选择：332 次候选弃牌中
169 次存在最高分完全并列，78 次满足 Pareto 改动，覆盖率 `23.49398%`。候选没有可调权重；高覆盖意味着必须直接
接受独立实战证伪，不能把它描述成 1%–5% residual。

## 固定 selection

- classic `seed=202638300..202638399`
- 100 副物理墙、每墙四座轮换
- 候选一席，对手三名 frozen Teacher；同墙全 Teacher baseline
- 唯一强度门槛：`paired_seed_score_delta_95pct_low > 0`
- 同时记录候选与 baseline 运行时间，但 selection 前不设置事后速度阈值
- 不做参数 sweep，不在同墙增加风险项、阈值、巡数门控或神经 logits
- 通过只允许先优化计算与做独立复核；不直接部署
- 失败则冻结“exact tie + shanten/ukeire Pareto”族，不把其动作蒸馏成训练标签

## 固定结果

全新 100 墙已完整运行：

- Teacher baseline：15.62 秒；候选：944.51 秒，慢 `60.46×`；
- 3,318 次弃牌中 1,742 次最高分完全并列（52.50%）；
- 814 次 Pareto 消歧（24.53%）；
- 814 次均没有改变向听，只增加公开有效进张，累计增加 5,879 张，立即胡牌张数累计增加 29；
- 候选 103/400 胜，总分 −32，均分 `−0.08`；
- paired 95% CI `[-3.5633,+3.4033]`。

严格正下界未通过，且点估计略负。结论不是“样本太少所以继续扫权重”，而是高覆盖的公开进张 Pareto 代理没有显示
长期价值；同样的 `progress` tie-break 不能从抚州规则直接迁移到厦门。候选不部署、不蒸馏、不增加风险／巡数／神经
二级排序；本族冻结。报告 SHA-256：
